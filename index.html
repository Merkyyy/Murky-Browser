Frequently asked questions.

Why do I see a "Windows protected your PC" warning?

Windows SmartScreen automatically flags newer independent software that lacks an expensive publisher certificate. Murky is completely safe, transparent, and malware-free. To install, simply click More info on the popup and select Run anyway.

Can I import data from my current browser?

Not yet. Full import tools for bookmarks, history, and passwords are currently in active development and will arrive in a near-future update.

Can I use extensions with Murky Browser?

Yes, Murky supports loading unpacked local extensions. However, we do not ship with a built-in extension marketplace.

How safe and private is Murky Browser?

Murky contains zero tracking telemetry or adware by default. Safety relies on standard secure sandboxing, though overall site security depends on the destinations you visit.
